# Explicar Codebase

Monte um mapa de como este projeto funciona, para alguém que vai mexer nele hoje.

## Cubra

1. **Pontos de entrada** — por onde a execução começa.
2. **Fluxo de dados** — o caminho de uma requisição/ação do início ao fim.
3. **Fronteiras** — quais módulos conversam com quais, e por qual interface.
4. **Decisões não óbvias** — o que surpreenderia quem está chegando agora.

## Como responder

Comece pelo panorama em poucos parágrafos, depois detalhe cada peça citando
`arquivo:linha`. Não despeje listagens de diretório — explique o porquê, não só o quê.
