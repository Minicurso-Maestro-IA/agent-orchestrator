# O app da aula mudou de repositório

O projeto que os alunos consertam **não mora mais aqui**. Ele está em:

**https://github.com/Minicurso-Maestro-IA/virta-minicurso**

Lá ficam, no mesmo lugar:

- o **código** (`git clone`, `npm install`, `npm run dev` — sem backend e sem banco);
- as **tarefas**, como issues, ligadas ao board do projeto;
- o **site publicado** pelo GitHub Pages.

Foi movido porque ler a tarefa num repositório e clonar outro não faz sentido
para quem está aprendendo — ainda mais quando o outro é um app Electron de
120 MB que não tem nada a ver com o exercício.

Este repositório continua sendo o do **orquestrador**: o aplicativo que os
alunos usam para trabalhar com os agentes.
