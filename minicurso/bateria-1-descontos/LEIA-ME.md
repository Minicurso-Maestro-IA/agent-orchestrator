# Bateria 1 — algoritmo de desconto

Pasta de trabalho da primeira bateria de teste do pipeline de três agentes.

Está vazia **de propósito**: quem escreve `descontos.js` e `descontos.test.js` é
o agente do papel 2. O `npm test` já está configurado (`node --test`), então não
há nada a instalar — Node puro, sem dependência.

```bash
npm test
```

O que o pipeline deve produzir aqui ao final:

- `ESPECIFICACAO.md` — escrito pelo papel 1
- `descontos.js` — escrito pelo papel 2
- `descontos.test.js` — idem
- os testes passando

O roteiro da bateria, com o pedido para colar e o gabarito do que observar, está
em `../BATERIAS-DE-TESTE.md`.
